Task 2: Automatic Night Lamp Using Arduino UNO and LDR Sensor

Objective

To design and simulate an automatic lighting system that detects changes in surrounding light intensity.

Components Used

- Arduino UNO
- LDR sensor
- 10 kΩ resistor
- 220 Ω resistor
- LED
- Breadboard and jumper wires

Working Principle

The LDR detects the surrounding light intensity and sends an analog reading to the Arduino UNO. The Arduino compares the reading with a programmed threshold and controls the LED accordingly.

Features

- Automatic light detection
- Automatic LED control
- Real-time sensor readings through the Serial Monitor
- Simple and low-cost circuit

Applications

- Automatic night lamps
- Lighting automation demonstrations
- Embedded systems learning

Project Files

- Automatic_Night_Lamp.ino — Arduino source code
- Circuit screenshots — demonstration of the circuit and LED operation
